未还原/约束说明
  • Linear 右侧"AI 助手"侧面板是产品形态差异,不引入(本项目是 C2 操作台,非 issue tracker)。
  • 卡片背景保留单层(无 row-stripe zebra),与原表格视觉一致,避免误读为斑马纹。
  • 导航"收藏"组预置 3 项(sessions / implants / beacons),但实际收藏关系未持久化(后续可加 localStorage)。
  • 终端 (xterm.js) 字体 / 配色保持不变——xterm 自管主题,与主面板解耦。
  • 表单字号从 13px 微降到 13px(等同),行高保留 1.5,以兼容既有中文输入。
  • Logo 渐变色由 indigo→violet 改为 purple→light-purple,与新 --accent-grad 对齐。
